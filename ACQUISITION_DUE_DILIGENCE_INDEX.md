# Acquisition Due-Diligence Index

## Public package

- `README.md`: platform position, ownership boundary, and production limitations.
- `DEMO_GUIDE.md`: repeatable reviewer route.
- `EVIDENCE_AND_DUE_DILIGENCE.md`: claim and evidence boundary.
- `INTEGRATION_EVIDENCE_TEMPLATE.md`: counterparty integration evidence record.
- `PERFORMANCE_REVENUE_EVIDENCE_TEMPLATE.md`: performance and revenue evidence record.
- `features.js`: canonical registry, merge lineage, and evidence classification.
- `integration-contract.js`: provider-neutral integration contract and validation logic.
- `.github/workflows/quality.yml`: automated quality and evidence checks.
- `.github/workflows/pages.yml`: public static demonstration deployment.

## Restricted diligence package to prepare separately

The following should not be placed in the public repository:

- Chain-of-title and intellectual-property records.
- Confidential source code or implementation secrets.
- Customer data, credentials, payment data, or government data.
- Signed contracts and counterparty confirmations.
- Bank, accounting, invoice, or audited financial evidence.
- Security reports, penetration-test details, and incident records.
- Production architecture secrets and operational access information.

## Release decision

The public package is ready for strategic review as a reference demonstration when automated checks pass. It is not, by itself, ready for a final acquisition conclusion. A final conclusion requires a controlled diligence room, verified evidence, independent review, and definitive transaction documentation.
